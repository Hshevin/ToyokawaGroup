## 7. 已知限制与风险

| 编号 | 限制 | 影响 | 建议 |
|------|------|------|------|
| L1 | 高德 Key 未配置 | 地图瓦片空白 | 在 `local.properties` 配置 `AMAP_API_KEY` |
| L2 | 非 GeoTIFF 仅百分比位置 | 无法输出真实经纬度 | 验收 GeoTIFF 全流程 |
| L3 | 旧任务数据 location 为空 | 需重开详情或清数据 | 迁移脚本或一次性清库 |
| L4 | 自动候选可能过多 | 核查工作量大 | 连通域过滤、提高面积阈值、或降低 `MAX_AUTO_ANOMALIES` |
| L5 | 首次 SAM 点击慢 | 解码器首次加载 | 已后台 prefetch，可接受 |
| L6 | 框选语义 | 合并已有区域，非空白处新建 | UI 文案已说明；空白补漏请用单击 |
| L7 | 大量改动未提交 | 协作/回归风险 | 按模块提交 PR |

3. **配置 AMAP Key**：核查页地图是否正常。
4. **报告 Tab**：生成并分享 JSON + 长图，核对与 B-097 标注一致。
